# Student Marks Prediction

## 📌 Project Description

This project predicts a student's marks based on the number of study hours using the Linear Regression algorithm.

## 🛠 Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## 📂 Files

- student_marks.csv
- student_marks_prediction.py
- requirements.txt

## ▶️ How to Run

1. Install the required libraries:

pip install -r requirements.txt

2. Run the program:

python student_marks_prediction.py

3. Enter the number of study hours.

4. View the predicted marks and graph.

## 📈 Algorithm

Linear Regression
